# Stranger Things


**Genre:** Sci-fi, Horror, Drama
**Platform:** Netflix
**Seasons:** 1,2,3,4


# Summary
Set in the 1980s, a group of kids in a small town investigate the
disappearance of their friend and uncover **secret experiments** and a
supernatural world called the **Upside Down**.
